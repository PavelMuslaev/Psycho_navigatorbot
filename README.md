# Psycho Navigator Bot

Telegram-клиент для прохождения опросников. Укажите BOT_TOKEN и API_BASE_URL в окружении и запустите бота командой `PYTHONPATH=src uv run python -m psychonavigatorbot.main`.

Бот показывает вопросы в одном сообщении и отправляет ответы в API после последнего вопроса. При временной ошибке кнопка «Повторить расчёт» отправляет сохранённые ответы. Кнопка отмены и команда /cancel удаляют текущую попытку.

Для MVP используется один процесс с MemoryStorage. После перезапуска прогресс теряется.
